🎮 Steam Games — Market & Player Engagement Analysis

An exploratory data analysis and Power BI dashboard project focused on understanding the Steam gaming market, player engagement, pricing, reviews, genres, and release trends.

📌 Project Overview

This project analyzes Steam game data to identify patterns and trends related to:

- 🎮 Game distribution and market composition
- 👥 Player engagement and Peak CCU
- 💰 Game pricing
- 🆓 Free vs paid games
- ⭐ User and Metacritic scores
- 👍 Positive and negative reviews
- 🎭 Game genres
- 📅 Release-year trends
- 📈 Recommendations and player engagement

The project combines **Python-based exploratory data analysis** with an interactive **Power BI dashboard**.
